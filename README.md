# Атлас Калининградской области

Интерактивный атлас мест и истории: 11 городов, 26 объектов и три эпохи — наши дни, время Канта, Тевтонский орден.

Навигация: **область → карта города → объект**. Можно сравнивать региональные маркеры: круглое фото с гербом, гербы и компактный вид.

## Тестовая публикация

[Открыть атлас на GitHub Pages](https://dmitrywroclaw-commits.github.io/Atlas-Kaliningrad/)

Сайт автоматически собирается и публикуется при отправке изменений в `main`. Статус — во вкладке **Actions**, workflow **Publish atlas to GitHub Pages**. Его можно запустить вручную кнопкой **Run workflow**. В **Settings → Pages** источником публикации должен быть **GitHub Actions**.

Это публичная тестовая версия. Для карты и внешних шрифтов нужен интернет. Внешний вид проверяет пользователь.

## Локальный запуск

Требуется Node.js 22:

```powershell
cd atlas-app
npm.cmd ci
npm.cmd run dev
```

Открыть http://127.0.0.1:5173/. Сборка: `npm.cmd run build`.

Исходники приложения и сведения об источниках: [atlas-app/README.md](atlas-app/README.md). Концепция проекта: [Atlas Docs](Atlas%20Docs/Kaliningrad_History_Atlas_Concept_TZ_v0.1.md).

В репозитории сохраняются изображения и сведения об их авторах и лицензиях. Зависимости, кеши и готовая сборка не добавляются в Git.
