# Атлас Калининградской области

Рабочий прототип тематической карты на основе исследовательского пакета этапа 2.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

Открыть [http://127.0.0.1:5173/](http://127.0.0.1:5173/).

## Сценарий

На карте области пять слоёв: **Места (города)**, **Русская история до 1917 года**, **Великая Отечественная**, **Фольклор**, **Литература**. В слое «Места» выбор города открывает его карту со всеми объектами, независимо от темы. В тематическом слое выбор точки открывает карту её города и карточку. Кнопка «К области» возвращает к выбранной теме.

Текущие данные: все 26 населённых пунктов из списка 01, все 58 записей из тематических списков 02–05 и 26 объектов первого прототипа. На уровне области маркеры компактные; при наведении точка раскрывается в круг с фотографией города или условной иллюстрацией. Старые состояния эпох сохранены в исходных данных `src/data.ts` и `src/places-data.json`, но больше не служат главной навигацией.

## Ограничения исследовательского прототипа

Все исследовательские записи представлены на карте. Для полей сражений, маршрутов, исчезнувших адресов и районов без точной геометрии используется ориентир, отмеченный пунктирной точкой и пояснением в карточке. Такой маркер показывает связанный населённый пункт или примерный район, а не точное место события. Памятник или музей события показывается отдельно от места самого события. Фольклор отмечен как рассказ, а не как исторический факт.

Координаты старых объектов и базовая карта взяты из первого прототипа. Для новых маркеров использованы локальная выгрузка OpenStreetMap `public/data/places-osm.json` и материалы исследовательского пакета. Точность каждого сюжета и ссылки на источники отражены в карточках.

## Файлы

- `scripts/build-research-data.py` — переносит все строки исследовательских таблиц в данные приложения.
- `src/research-data.json` — 26 населённых пунктов и 58 тематических записей.
- `src/themes.ts` — пять слоёв и привязка исследовательских данных к карте.
- `src/App.tsx` — переходы между областью, городом и точкой; URL-параметры `layer`, `city`, `place`.
- `src/AtlasMap.tsx` — карта MapLibre и маркеры.
- `src/ObjectCard.tsx` — карточка точки.

Сборка: `npm.cmd run build`. Локальный сервер: `npm.cmd run dev`.
