# Атлас Калининграда — исследовательский пакет этапа 2

Версия: **v0.2-research**  
Дата среза: **2026-09-30**

## Задача этапа

Перевести прототип от трёх крупных «эпох» к тематическим слоям карты и собрать проверяемый корпус мест, который позже можно преобразовать в GeoJSON/JSON приложения.

Текущие исторические фильтры **«Кант»** и **«Тевтонский орден»** предлагается **скрыть в интерфейсе, но не удалять из данных**. Их можно вернуть позднее как дополнительные временные/персональные срезы.

- `06_map_filters_and_data_model.md` — предлагаемые фильтры и модель данных.

## Статусы геопривязки

- `ready_point` — можно наносить как точку после технической проверки координат.
- `rough_anchor` — координата дана только как ориентир населённого пункта; не считать точным местом события.
- `needs_georef` — историческое место подтверждено, но точную геометрию ещё надо установить.
- `area_required` — событие нельзя корректно свести к одной точке; нужен полигон/линия/кластер.
- `research` — интересный кандидат, требующий дополнительной редакционной проверки.

## Важное редакционное правило

**Событие, место события, памятник событию и музей о событии — разные сущности.** Например, поле боя при Гросс-Егерсдорфе, современный мемориал на поле и памятная доска в Черняховске должны быть отдельными объектами, связанными одним `event_id`.
